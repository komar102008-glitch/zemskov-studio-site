# Zemskov studio

Личное портфолио Никиты. Статический сайт без сборки.

На главной — короткое представление и интерактивный цветок с шестью темами. Личные тексты находятся в flower-content.js. Демонстрационные проекты и форма брифа удалены; реальных работ и контактов пока нет.

На мобильных экранах используются заранее отрисованные WebP-слои цветка. На широких экранах — SVG. Учтена настройка уменьшения движения.

GitHub Pages публикует корень ветки main.
