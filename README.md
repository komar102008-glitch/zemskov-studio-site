# Zemskov studio

Портфолио Никиты: сайты для специалистов и небольшого бизнеса.

Основной адрес: https://komar102008-glitch.github.io/zemskov-studio-site/

- index.html — актуальный сайт; cinema.html — совместимый адрес той же страницы.
- portfolio-v1.html — архив прежней главной.
- cinema-botanical.html — предыдущая тёмная 3D-сцена.
- polymer.css — оформление и адаптивная вёрстка.
- polymer-ui.js, polymer-scene.js — навигация цветка и сцена Three.js.
- portfolio.js — FAQ, анимации услуг и отправка заявки.
- contact-config.js — открытые настройки получателя FormSubmit; секретных ключей нет.

В услугax указаны ориентиры цен, сроки и состав работ. Готовые клиентские кейсы и отзывы не выдуманы. Форма использует FormSubmit; почта активирована владельцем, доставка тестовой заявки подтверждена. Есть прямая ссылка на почту и копирование заявки.

GitHub Pages публикует корень ветки main. Обе актуальные HTML-страницы содержат canonical на основной адрес. Старые CSS/JS/изображения оставлены для архивных версий.
